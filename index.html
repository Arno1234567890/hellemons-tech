Home EMS Rclone

Home EMS Rclone is a private, owner-operated application used to synchronize Home Energy Management System (EMS) files with the owner's Google Drive using rclone.

Purpose

The application supports automated transfer of EMS reports and datasets from the owner's Home Assistant environment to a designated folder in the owner's Google Drive. It is not offered as a public service and has no external users.

Google Drive access

The application uses Google OAuth to authorize rclone. The configured Google Drive scope may technically permit broad access to the owner's Drive, but the Home EMS configuration uses that access only for the designated EMS synchronization workflow.
