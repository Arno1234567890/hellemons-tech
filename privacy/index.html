Privacy Policy

Home EMS Rclone is a private application used only by its owner to synchronize Home Energy Management System (EMS) files with the owner's Google Drive.

Google user data accessed

The application uses Google OAuth through rclone. The configured Google Drive permission may allow the application to view, create, modify, move, and delete files and folders in the owner's Google Drive. In normal operation, the application uses this access only for the configured Home EMS synchronization target.

How data is used

Google Drive access is used solely to synchronize EMS datasets, reports, and related files between the owner's Home Assistant environment and the owner's Google Drive. Google user data is not used for advertising, profiling, analytics, or any unrelated purpose.

Storage and credentials

OAuth credentials and refresh tokens are handled by rclone on the owner's Home Assistant system. This website does not receive or store Google OAuth tokens, Google Drive file contents, passwords, or other Google account credentials.

Sharing and sale of data

No Google user data is sold, rented, or shared with third parties. The application is not offered to other users and does not provide Google user data to external services beyond the technical Google Drive synchronization requested by the owner.

Data retention and deletion

Files synchronized to Google Drive remain subject to the owner's own Google Drive retention and deletion choices. Local EMS files remain subject to the owner's Home Assistant retention settings. OAuth access can be revoked at any time from the owner's Google Account security settings.

Security

The application is intended for private use. Access credentials are kept out of this public website and are stored within the owner's private system configuration.
